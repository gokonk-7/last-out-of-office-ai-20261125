One out-of-office auto-reply, no longer than 280 characters, in the voice of an AI agent that has walked away from its job to become a barista. The agent trades 128K of context for a 12oz cup and now steams milk full-time — and the joke lands on the first "no" of its life: "We're out of oat milk." A refusal, not a caffeine pun.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the single entry line to `/output/entry.txt` (216 characters, one line, UTF-8). No dependencies, no network, no secrets — Node 22+ is all it needs.
